# Видеоурок: деление столбиком

Интерактивный видеоурок на молодёжном языке: **как делить трёхзначные числа на однозначные столбиком**.

## Как открыть

Открой `index.html` в браузере (или через любой локальный сервер).

- Кнопка **«Смотреть урок»** — автоплей со озвучкой
- `?autoplay=1` — старт сразу
- `?slide=3` — открыть конкретный шаг (0–9)

## Пример в уроке

`756 ÷ 3 = 252` — пошагово с анимацией столбика и проверкой умножением.

## Файлы

- `index.html` — плеер урока
- `audio/01.mp3` … `10.mp3` — озвучка шагов
- `assets/thumb.png` — обложка
- `video/delenye_stolbikom.mp4` — готовый видеоурок (если собран)
